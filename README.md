# AI // EVOLUTION · AI 发展历程

一个纯静态的 AI 发展史交互站点：从 1943 年的麦卡洛克-皮茨神经元，到 2025 年的推理模型与智能体，
20 个关键节点、5 个时代、6 种研究范式、20 座城市，每个节点都能点开进入完整档案并播一段讲解短片。

> 除地图瓦片外，无框架、无 CDN、无外链字体、无图片资源 —— 界面与影片都由 HTML / CSS / Canvas 现场绘制，
> 直接双击 `index.html` 即可浏览（地图在离线状态下会自动降级为「地点索引」）。

## 功能

- **搜索**：一个输入框就能查年份、人物、机构、技术与地点；支持 `2016`、`辛顿`、`注意力`、`杭州` 这类关键词，
  多词为「与」关系，命中字段高亮显示，结果可直接回车进入档案，时间轴同时被过滤。快捷键 `/` 或 `Ctrl/⌘ + K`。
- **时间轴**：1943 — 2025，20 个节点按 5 个时代分组，可按标签筛选；卡片支持 3D 倾斜与光斑跟随。
- **节点档案**：每个节点 5 段正文（背景 / 突破 / 细节 / 影响 / 局限）+ 3 组关键数据 + 当事人原话。
- **介绍影片**：每个节点自带 3 章 × 6 秒的 Canvas 程序化短片，支持播放、暂停、拖动、跳章与键盘控制。
- **六种范式**：符号主义 → 连接主义 → 知识工程 → 深度学习 → 生成式模型 → 推理与智能体，卡片可翻转直达节点。
- **地理坐标**：通栏世界地图，20 座城市 / 33 个发生地。年份滑块按时间回放，点击光点或城市索引，
  右侧卡片列出该地发生的节点与年份，可一键进入档案；档案页也有「在地图上查看」入口。
- **深链接**：`#/node/<id>` 可直接定位到某个节点，支持浏览器前进 / 后退。
- **无障碍**：焦点陷阱、`inert` 背景冻结、ESC 关闭、组合框键盘操作、`prefers-reduced-motion` 全量降级。

## 目录

```
index.html        单页入口（含地图鉴权配置）
css/style.css     全部样式（含响应式与矮视口适配）
js/data.js        20 个节点 + 6 种范式的数据
js/geo.js         节点的发生地：城市 / 国家 / 经纬度 / 一句话说明
js/app.js         渲染、搜索、路由、影片引擎、地图、背景动画
```

## 本地运行

```bash
# 方式一：直接打开（地图会降级为地点索引）
start index.html

# 方式二：起一个静态服务
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 地图说明（合规）

地图使用**腾讯位置服务 GL JS**（国内合规地图源；不使用 Google / OSM / Mapbox 等）。坐标以 WGS-84 记录，
渲染前统一转换为 GCJ-02。底图自带官方审图号与版权标识，不做自定义样式覆盖。

- 在 WorkBuddy 预览环境中运行时，前端不出现任何密钥：SDK 通过运行时的钥匙代理（`_TMapSecurityConfig`）鉴权。
- 部署到 GitHub Pages 等自建环境时，代理地址不可用，地图会自动降级为「地点索引」。
  若要在线上也显示地图，请到 <https://lbs.qq.com> 申请自己的 key，填入 `index.html` 中的
  `window.AI_TMAP_KEY`（同时配置 Referer 域名白名单）。

## 说明

影片为程序化动画，非纪录片片段（版权原因）。若某个节点配置了 `video` 字段，
播放器会自动切换为真实 `<video>`；否则显示右上角的「相关纪录片」搜索出口。
